## ADDED Requirements

### Requirement: Корреляция прикладных HTTP-операций и upgrade

Общий HTTP middleware SHALL сохранять `X-Request-Id` в контексте и заголовке ответа подключённых handlers. Поддерживаемый upgrade SHALL проходить через обёртку HTTP-ответа. Запись операции SHALL отражать корректный результат без раскрытия авторизационных данных.

#### Scenario: Успешный Connect-вызов и WebSocket handshake

- **GIVEN** через bootstrap смонтированы Connect и WebSocket handlers, клиенты отправляют допустимые идентификаторы запроса
- **WHEN** Connect возвращает ответ и WebSocket переходит в состояние 101
- **THEN** обработчики получают нужный контекст, ответы содержат тот же ID, а журнал содержит коррелированные результаты операций

#### Scenario: Прикладной отказ сохраняет контекст

- **GIVEN** прикладной handler возвращает безопасную ошибку Connect
- **WHEN** клиент вызывает его с допустимым заголовком
- **THEN** ошибку можно связать с записью по request ID, тело запроса и авторизационные данные отсутствуют в журнале
