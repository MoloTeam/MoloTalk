# Web Client Shell

## Purpose

Определяет запускаемый каркас веб-клиента, границы его компонентов и базовую навигацию по issue #7 и клиентской C3.

## ADDED Requirements

### Requirement: Команды разработки и проверки

Из каталога web SHALL работать npm run dev, lint, typecheck, test и build после установки зависимостей по lock-файлу. Запуск каркаса, сборка и автоматические проверки клиента SHALL выполняться без запущенных backend-сервисов.

#### Scenario: Запуск из чистой копии

- **GIVEN** установлены документированные версии Node и npm, зависимости установлены через npm ci
- **WHEN** разработчик запускает dev, открывает корневой экран и выполняет lint, typecheck, test и build
- **THEN** экран загружается, проверки завершаются успешно, а сборка создаёт пригодные для раздачи SPA-файлы

### Requirement: Компоненты и навигация

Каркас SHALL выделять вход и профиль, диалоги и группы, редактор, историю и статусы, обмен данными и состояние клиента. Компоненты представления SHALL вызывать переданные действия и отображать состояние. Навигация SHALL поддерживать прямой вход по известному маршруту и показывать состояние «Страница не найдена» для неизвестного пути в dev.

#### Scenario: Навигация по оболочке приложения

- **GIVEN** каркас запущен с тестовыми зависимостями
- **WHEN** пользователь открывает вход, список диалогов и страницу конкретного диалога, затем обновляет страницу
- **THEN** отображаются соответствующие части каркаса, редактор и история получают выбранный chatId, обновление сохраняет маршрут

#### Scenario: Действие представления

- **GIVEN** экран диалогов получил подставное действие выбора диалога
- **WHEN** пользователь выбирает диалог
- **THEN** экран передаёт идентификатор действию; тест выполняется без прямого вызова RPC или сокета из React-компонента
