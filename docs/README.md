## Порядок источников

1. FS задаёт требования к поведению и критерии приёмки.
2. HLD задаёт архитектурные решения и границы компонентов.
3. Действующие спецификации в [OpenSpec](../openspec/specs/) уточняют поведение и проверки конкретных изменений.

Для формы действующего API сверяйся с [proto](../api/proto/). Если источники расходятся, зафиксируй расхождение в карточке и согласуй решение до реализации.
