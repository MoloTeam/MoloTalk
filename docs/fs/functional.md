# Функциональные требования

| Идентификатор | Модуль | Требование |
| --- | --- | --- |
| F_Auth_1 | Auth | Пользователь может зарегистрировать учётную запись, указав логин (или e-mail), имя и пароль. |
| F_Auth_2 | Auth | Кнопка регистрации неактивна, пока не заполнены поля: «Логин»/«E-mail», «Имя» и «Пароль». |
| F_Auth_3 | Auth | Система отклоняет регистрацию, если указанный логин (e-mail) уже используется другой учётной записью, и отображает сообщение об ошибке. |
| F_Auth_4 | Auth | Пароль, вводимый при регистрации, должен удовлетворять общим требованиям к паролю (см. F_Pwd_1 … F_Pwd_3). Система отклоняет регистрацию при нарушении любого из них и отображает соответствующее сообщение об ошибке. |
| F_Auth_5 | Auth | Пользователь может войти в систему, указав логин и пароль зарегистрированной учётной записи. |
| F_Auth_6 | Auth | Кнопка авторизации неактивна, пока не заполнены поля: «Логин»/«E-mail» и «Пароль». |
| F_Auth_7 | Auth | При вводе неверного логина/E-mail или пароля на экране входа отображается сообщение об ошибке авторизации. |
| F_Auth_8 | Auth | Пользователь может завершить текущий сеанс с переходом на страницу авторизации. |
| F_Profile_1 | Profile | Пользователь может изменить отображаемое имя своего профиля. |
| F_Profile_2 | Profile | Система отклоняет попытку сохранить отображаемое имя, если поле имени пустое. |
| F_Profile_3 | Profile | Пользователь может заменить изображение аватара своего профиля. |
| F_Profile_4 | Profile | Пользователь может сменить пароль от своего аккаунта. |
| F_Profile_5 | Profile | Система отклоняет смену пароля, если пользователь ввёл неверный текущий пароль, и отображает сообщение об ошибке. |
| F_Profile_6 | Profile | Новый пароль при смене должен удовлетворять общим требованиям к паролю (см. F_Pwd_1 … F_Pwd_3). Система отклоняет смену пароля при нарушении любого из них и отображает соответствующее сообщение об ошибке. |
| F_Profile_7 | Profile | Система отклоняет смену пароля, если содержимое полей ввода нового пароля и повтора нового пароля не совпадает, и отображает сообщение об ошибке. |
| F_Profile_8 | Profile | Система отклоняет загрузку аватара, если формат файла отличен от JPG, JPEG или PNG, и отображает сообщение об ошибке. |
| F_Profile_9 | Profile | Система отклоняет загрузку аватара, если размер файла превышает 5 МБ, и отображает сообщение об ошибке. |
| F_Msg_1 | Msg | Пользователь может отправить текстовое сообщение собеседнику в открытом чате. |
| F_Msg_2 | Msg | Отправленное текстовое сообщение отображается в чате у получателя. |
| F_Msg_3 | Msg | Кнопка отправки сообщения неактивна, если поле ввода пустое и к сообщению не прикреплено ни одного файла. |
| F_Msg_4 | Msg | Если сообщение не удалось доставить на сервер из-за потери соединения, рядом с ним отображается статус «Не отправлено» и становится доступна повторная отправка. |
| F_Msg_5 | Msg | Рядом с отправленным сообщением отображается индикатор статуса «Доставлено» после подтверждения сервером факта доставки получателю. |
| F_Msg_6 | Msg | Рядом с отправленным сообщением отображается индикатор статуса «Прочитано» после того, как получатель открыл чат, содержащий это сообщение. |
| F_Msg_7 | Msg | Пользователь может изменить текст ранее отправленного им сообщения. |
| F_Msg_8 | Msg | Пользователь не может редактировать сообщение, отправленное другим участником чата. |
| F_Msg_9 | Msg | Изменённый текст сообщения отображается у всех участников чата с пометкой «изменено». |
| F_Msg_10 | Msg | Пользователь может удалить ранее отправленное им сообщение. |
| F_Msg_11 | Msg | Пользователь не может удалить сообщение, отправленное другим участником чата. |
| F_Msg_12 | Msg | Удалённое сообщение не отображается в чате у всех участников. |
| F_Group_1 | Group | Пользователь может создать групповой чат, указав его название. |
| F_Group_2 | Group | Система отклоняет создание группового чата с пустым названием. |
| F_Group_3 | Group | Владелец или администратор группового чата может пригласить в него другого пользователя. |
| F_Group_4 | Group | Участник группового чата без роли «владелец» или «администратор» не может пригласить нового участника. |
| F_Group_5 | Group | Система отклоняет добавление нового участника в групповой чат, если в нём уже 100 участников, и отображает сообщение об ошибке. |
| F_Group_6 | Group | Владелец или администратор может удалить участника из группового чата. |
| F_Group_7 | Group | Участник может самостоятельно покинуть групповой чат. |
| F_Group_8 | Group | Владелец группового чата может назначить участнику роль администратора. |
| F_Group_9 | Group | При выходе владельца из группового чата роль владельца автоматически переходит одному из администраторов; если администраторов нет — случайному участнику группы. |
| F_History_1 | History | Пользователь может просмотреть историю сообщений открытого чата. |
| F_History_2 | History | Пользователь может подгрузить более ранние сообщения чата, прокручивая историю вверх (постраничная подгрузка). |
| F_History_3 | History | Отправленное сообщение отображается во всех активных сеансах пользователя. |
| F_Presence_1 | Presence | Пользователь может видеть текущий статус присутствия («в сети» / «не в сети») другого пользователя. |
| F_Media_1 | Media | Пользователь может прикрепить файл к отправляемому сообщению. |
| F_Media_2 | Media | Прикреплённый файл отображается получателю вместе с текстовым сообщением. |
| F_Media_3 | Media | Система отклоняет прикрепление файла в формате, отличном от JPG, JPEG, PNG, GIF (для изображений) и PDF, DOCX (для документов), и отображает сообщение об ошибке с перечнем поддерживаемых форматов. |
| F_Media_4 | Media | Система отклоняет прикрепление файла размером более 20 МБ и отображает сообщение об ошибке. |
| F_Media_5 | Media | Система отклоняет прикрепление более 5 файлов к одному сообщению. |
| F_Pwd_1 | Pwd | Система отклоняет пароль, если его длина меньше 6 символов или больше 64, и отображает сообщение об ошибке с указанием допустимой длины. |
| F_Pwd_2 | Pwd | Система отклоняет пароль, если он содержит пробелы, буквы кириллицы, эмодзи, управляющие символы или иные символы, не входящие в разрешённый набор: латинские буквы A–Z, a–z, цифры 0–9 и специальные символы ! @ # $ % ^ &amp; * ( ) _ + - = [ ] { } ; : ' " \| , . &lt; &gt; / ?. Система отображает сообщение об ошибке с указанием допустимых символов. |
| F_Pwd_3 | Pwd | Система отклоняет пароль, если он не содержит хотя бы 1 заглавной буквы, 1 строчной буквы, 1 цифры и 1 специального символа, и отображает сообщение об ошибке с указанием требований к содержимому пароля. |
