# Нефункциональные требования

| Идентификатор | Модуль | Требование |
| --- | --- | --- |
| NF_Sec_1 | Auth | Пароль пользователя хранится в базе данных в виде хеша, вычисленного с использованием соли; хранение пароля в открытом виде не допускается. |
| NF_Perf_1 | Profile | Изменения профиля пользователя (имя, аватар) отображаются другим пользователям не позднее чем через 60 секунд после сохранения. |
| NF_Cap_1 | Msg | Максимальная длина текстового сообщения ограничена 4096 символами (в кодировке UTF-8). |
| NF_Perf_2 | Msg | Время от отправки текстового сообщения до его отображения у получателя не превышает 250 мс. |
| NF_Perf_3 | Msg | Время обновления индикатора статуса сообщения (доставлено / прочитано) после подтверждения сервером не превышает 200 мс. |
| NF_Perf_4 | Msg | Изменения, вносимые редактированием или удалением сообщения, отображаются у всех участников чата не позднее чем через 250 мс. |
| NF_Cap_2 | Group | Групповой чат поддерживает не более 100 участников включительно. |
| NF_Perf_5 | Group | Изменение состава участников группового чата (добавление / удаление) отображается у всех участников не позднее чем через 500 мс. |
| NF_Perf_6 | Group | Изменение роли участника вступает в силу и отображается у всех участников группового чата не позднее чем через 500 мс. |
| NF_Perf_7 | History | Время загрузки последних 100 сообщений чата не превышает 1 секунду. |
| NF_Data_1 | History | История переписки хранится и доступна пользователю не менее 30 дней. |
| NF_Perf_8 | History | Новое сообщение появляется в других активных сеансах пользователя не позднее чем через 250 мс после отправки. |
| NF_Perf_9 | Presence | Отображаемый статус присутствия пользователя обновляется не позднее чем через 30 секунд после его фактического изменения. |
